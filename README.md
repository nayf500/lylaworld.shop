# متجر عالم ليلى — ساعات نسائية

متجر إلكتروني كامل: واجهة عرض، سلة تسوق، صفحة دفع مربوطة ببوابة **Moyasar**، قاعدة بيانات SQLite حقيقية، ولوحة تحكم لإدارة المنتجات والطلبات.

**بدون أي مكتبات خارجية** — الخادم مبني بالكامل على وحدات Node.js المدمجة (`http`, `node:sqlite`)، فلا حاجة لتشغيل `npm install`.

## المتطلبات
- Node.js **22.5** أو أحدث (لأنه يحتاج وحدة `node:sqlite` المدمجة). تحققي بالأمر: `node --version`

## التشغيل محلياً
```bash
cd hana-store
cp .env.example .env      # ثم عدّلي القيم بداخله
node server.js
```
افتحي المتصفح على: `http://localhost:3000`

قاعدة البيانات تُنشأ تلقائياً في ملف `store.sqlite` عند أول تشغيل، مع ٨ منتجات تجريبية.

## ربط بوابة الدفع Moyasar
١. أنشئي حساب تاجر على [dashboard.moyasar.com](https://dashboard.moyasar.com) (يتطلب سجل تجاري سعودي أو حساب فردي حسب سياستهم الحالية — تحققي من الموقع للتفاصيل الحديثة).
٢. من لوحة Moyasar، انسخي:
   - **Publishable Key** (يبدأ بـ `pk_`) → ضعيه في `MOYASAR_PUBLISHABLE_KEY`
   - **Secret Key** (يبدأ بـ `sk_`) → ضعيه في `MOYASAR_SECRET_KEY`
٣. أثناء الاختبار استخدمي مفاتيح `test` التي توفرها Moyasar وبطاقات الاختبار الخاصة بهم قبل التحويل لمفاتيح `live`.
٤. عدّلي `SITE_URL` في `.env` إلى رابط موقعكِ الحقيقي بعد النشر، لأن رابط تأكيد الدفع (`callback_url`) يعتمد عليه.

**كيف يعمل الدفع هنا تحديداً:**
- عند الضغط على "المتابعة إلى الدفع"، يُنشئ الخادم طلباً بحالة `pending` في قاعدة البيانات ويحسب السعر من قاعدة البيانات نفسها (وليس مما يرسله المتصفح، لمنع التلاعب بالسعر).
- تظهر نموذج بطاقة Moyasar الرسمي (Hosted Fields) لإدخال بيانات البطاقة، وتذهب بيانات البطاقة مباشرة إلى Moyasar (لا تلمس خادمكِ إطلاقاً — وهذا مطلوب لأي متجر يتعامل مع بطاقات).
- بعد الدفع، يُعيد Moyasar توجيه الزائر إلى `/api/payment-callback`، وهناك **يتحقق الخادم من حالة الدفع الحقيقية عبر Moyasar API** (لا يثق بالرابط وحده)، ثم يحدّث حالة الطلب ويوجّه المستخدم لصفحة الشكر.

## لوحة التحكم
الرابط: `/admin/login.html`
كلمة المرور الافتراضية موجودة في `.env` تحت `ADMIN_PASSWORD` — **غيّريها قبل النشر**.
من اللوحة يمكنك: إضافة/تعديل/حذف المنتجات، وعرض جميع الطلبات وحالاتها.

## النشر (الاستضافة)
أي استضافة تدعم Node.js 22+ تعمل (مثل Railway، Render، أو VPS عادي). الخطوات عموماً:
1. ارفعي مجلد المشروع كاملاً (عدا `store.sqlite` و `.env` إن كانا موجودين محلياً فقط).
2. أضيفي متغيرات البيئة من `.env.example` في إعدادات الاستضافة.
3. أمر التشغيل: `node server.js`

> ملاحظة: `node:sqlite` تخزّن البيانات في ملف واحد على القرص. لمتجر بحجم أكبر مستقبلاً (زيارات عالية جداً أو نسخ احتياطي تلقائي)، يمكن لاحقاً الانتقال لقاعدة بيانات مُدارة (Postgres مثلاً) دون تغيير كبير في الكود لأن دوال `db.js` معزولة عن بقية الخادم.

## بنية المشروع
```
hana-store/
  server.js         الخادم الرئيسي (المسارات API + تقديم الملفات)
  db.js              كل التعامل مع قاعدة البيانات
  package.json
  .env.example
  public/
    index.html       الرئيسية
    shop.html        كل المنتجات + فلترة
    product.html      صفحة تفاصيل منتج
    cart.html         السلة
    checkout.html     الدفع (مربوط بـ Moyasar)
    thank-you.html    تأكيد الطلب
    admin/
      login.html
      dashboard.html   إدارة المنتجات والطلبات
    css/style.css
    js/ (main.js, cart.js)
```
